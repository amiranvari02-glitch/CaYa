# Caya

Caya is an Asset Integrity Management Platform with an initial focus on Risk-Based Inspection (RBI).

## Current Implementation

This repository starts from the approved Caya Software Architecture Specification (CSAS Version 1.0).

The implementation will be developed incrementally, beginning with:

1. Repository Foundation
2. Application Shell
3. Engineering Data
4. Equipment
5. Calculation Foundation
6. Inspection
7. Corrosion
8. RBI

## Architecture Principle

Caya separates engineering data ownership, calculation, engineering interpretation, engineering decision, workflow, approval, and auditability.

> Caya shall provide an integrated, revision-controlled, traceable, calculation-capable Asset Integrity platform in which engineering domains retain ownership of their technical responsibilities, controlled computational services provide reproducible results, workflows govern execution, and human engineering authority remains responsible for interpretation, decision, and approval.
